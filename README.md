# Connecta Landing Page

Bem-vindo ao repositório do **Connecta Landing Page**. Este projeto é composto por uma landing page moderna para a **Connecta CI** e um backend para gerenciar o envio de mensagens de contato via email.

## Estrutura do Projeto

O projeto é dividido em dois diretórios principais:

*   **`frontend/`**: A interface do usuário (Landing Page) construída com React, Vite e TailwindCSS.
*   **`backend/`**: A API (Servidor) construída com Node.js, Express e TypeScript, responsável pelo envio de emails.

## Como começar

Para rodar o projeto completo, você precisará configurar e iniciar tanto o frontend quanto o backend.

### Pré-requisitos

*   Node.js instalado.

### Passo a Passo Rápido

1.  **Backend**:
    *   Entre na pasta: `cd backend`
    *   Instale as dependências: `npm install`
    *   Configure o arquivo `.env` (veja o README dentro da pasta `backend` para detalhes).
    *   Inicie o servidor: `npm run dev`

2.  **Frontend**:
    *   Abra um novo terminal e entre na pasta: `cd frontend`
    *   Instale as dependências: `npm install`
    *   Inicie o frontend: `npm run dev`

Acesse a aplicação em `http://localhost:5173`.
